# Laptop Dataset — Exploratory Data Analysis with dplyr

## 📖 Project Description
This repository contains an **exploratory data analysis (EDA)** of a laptop dataset using **`dplyr`** and **`readr`** in R.  
The script answers 12 core questions plus an advanced challenge set, covering filtering, sorting, creating new variables, grouping, summarizing, and finding top-N records.

## 🛠️ Requirements
- **R** (version 4.0 or newer recommended)
- **RStudio** (recommended)
- Packages:
  - `dplyr`
  - `readr`

Install with:
```r
install.packages(c("dplyr", "readr"))
